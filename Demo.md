## About

**pytemplate-cli** is a professional python cli tool template.

### Key Features

- argparse with subcommands
- Structured logging
- YAML/JSON config
- Unit tests with pytest
- Type hints throughout
- Error handling

---

## Tech Stack

- Python
- argparse
- logging
- pytest
- YAML

---

## Controls & Usage

| Control | Action |
|---------|--------|
| `--help` | Show usage |
| `--config` | Config file path |
| `--verbose` | Verbose mode |
| `subcommands` | Various commands |
